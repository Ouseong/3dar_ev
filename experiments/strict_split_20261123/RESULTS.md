# 원본 음원이 겹치지 않는 엄격 분할 — 지도학습 2종 재실행 (2026-11-23)

## 분할 (`make_strict_split.py` → `runs/strict_split_20261123/seed{42,43,44}.json`)
- 원본 음원 879개가 녹음 사이에 재사용됨(최대 20회). 음원을 공유하는 녹음끼리 이으면 930개짜리 덩어리 → 모든 녹음을 쓰면서 음원이 안 겹치게 나누는 것은 불가능.
- 방법: 원본 음원 파일을 학습/검증/시험에 배정하고, 음원 3개가 모두 같은 쪽인 녹음만 사용. 섞이는 녹음은 버림. 남는 녹음 수가 최대가 되고 검증·시험이 남은 것의 약 10%가 되도록 simulated annealing으로 배정. 분할 간 음원 겹침 0을 assert로 확인.

| 43 | 658 | 82 | 81 | 379 | 174 / 69 |
| 44 | 651 | 81 | 81 | 387 | 159 / 84 |

- 시험이 고장 0곳 녹음 쪽으로 쏠림(41–57개). 고장 종류별 시험 구간 수가 적음(5–28).
