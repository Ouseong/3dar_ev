## 4. 고장 성분 손실이 3DAR 상쇄 때문인가 (`facing_vs_away.py`, 1개 스피커 녹음)
마이크가 스피커를 향하는 90°(facing)와 반대쪽 90°(away)에서, 같은 시간 구간의 원본과 비교한 고장−정상 차이(AUC):
| 성분 | 구간 | 원본 | 녹음 |
|---|---|---|---|
| PWM 5 kHz 선 | 향할 때 | +15.7 dB (1.00) | +7.7 dB (0.94) |
| | 반대쪽 | +15.6 dB (1.00) | +1.2 dB (0.65) |
| Whine order 16 비율 | 향할 때 / 반대쪽 | +9.9 / +9.7 dB | +3.6 / +4.3 dB |
| Wind 대역 | 향할 때 / 반대쪽 | +2.7 / +3.5 dB | +1.2 / +1.1 dB |
| Imbalance order 2 | 향할 때 / 반대쪽 | +8.9 / +9.0 dB | +2.4 / +3.6 dB |
- PWM(5 kHz): 반대쪽에서는 3DAR 상쇄로 거의 사라짐(+1.2 dB). 향할 때도 원본의 절반(+7.7 dB) → 상쇄 외의 손실(배경 소음·반사 추정)도 약 8 dB.
- Whine·Wind·Imbalance: 향하든 반대든 손실이 같음 → 3DAR 상쇄 때문이 아님.
- 주의: 1초 안팎의 짧은 구간이라 order 1 지표(0.1 kHz)는 원본에서도 분해가 안 됨(+0.3 dB).
