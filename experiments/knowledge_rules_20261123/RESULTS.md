# 고장 특징 지식만으로 판정 (학습 없음) — 3개 스피커 구간, 엄격 분할 (2026-11-23)

## 방법 (`knowledge_detector.py`, `evaluate.py`)
- 논문 Sec. 3.3 고장 설계를 규칙으로 측정. 구간(앞/오른쪽/뒤, 뒤는 두 조각 시간 가중 평균)마다:
  - Imbalance: order 1, 2 / Modulation: order 7.9, 8.1 측대역 / Whine: order 16 → order tracking 스펙트럼에서 주변 대비 피크(dB)
  - PWM: 5,000 Hz 피크(dB) / Wind: 3.9–5.6 kHz 대역 − 주변 대역(dB)
- order tracking: 추정 RPM(재생 구간 기반, 측정값 아님)으로 회전각 재샘플링(512 샘플/회전). 녹음마다 정상 order 4/8/12/16 선이 가장 선명해지도록 시작·끝 RPM과 곡률을 미세 보정(라벨 안 씀). 선명도 8.4 → 11.0 dB, 보정량 평균 시작 −0.9%.
- 정상 기준: 엄격 분할 학습 쪽의 고장 0곳 녹음 정상 구간만, 위치별 평균·표준편차 → z. 점수 = 다섯 특징 z의 최댓값. 고정 임계 z>3(라벨로 조정 안 함).
- 시험: `runs/strict_split_20261123` 시험 구간(원본 음원 안 겹침).
- 출력: `runs/knowledge_rules_20261123/roi_features_refined.json`, `evaluation_roi_features_refined.json`
