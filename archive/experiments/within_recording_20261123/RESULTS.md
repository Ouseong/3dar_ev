# 녹음 안 비교 — 빈 방향(45–135°) 기준 비지도 이상 점수 (2026-11-23)

- 코드 `within_recording_anomaly.py`, 결과 `runs/within_recording_20261123/{scores.csv, summary.json}`
- 조각 특징 − 같은 녹음 빈 방향 특징 → 위치별 정상(고장 0곳 녹음) 분포에서 Mahalanobis 거리. 평가 녹음과 원본 음원을 공유하는 정상 녹음은 기준에서 제외. 고장 라벨은 평가에만 사용.
- 특징: mel(64대역 시간평균 dB) / know(지식 규칙 6개). 빈 방향을 빼는 것(within)과 안 빼는 것(raw) 비교.

| | mel within | mel raw | know within | know raw |
|---|---|---|---|---|
| AUC 전체 | 0.743 | 0.763 | 0.574 | 0.746 |
| AUC 고장 1·2곳 녹음 안 | 0.549 | 0.482 | 0.482 | **0.645** |
| 1곳 녹음 고장 조각 1등 (무작위 0.33) | 0.317 | 0.300 | 0.320 | **0.457** |
| 1곳 녹음 앞·뒤 중 고장이 높음 (무작위 0.50) | 0.490 | 0.541 | 0.447 | **0.607** |
| 고장 종류 vs 깨끗한 정상 AUC (Imb/Mod/Whine/PWM/Wind) | .88/.89/.96/.90/.93 | .97/.98/.99/.98/.98 | .64/.60/.74/.67/.64 | .79/.75/.91/.89/.83 |

- 빈 방향을 빼도 방향 구분은 무작위 수준(0.32, 0.49). 빈 방향은 녹음의 다른 시점(0.5–1.5 s, 다른 RPM)이라 빼면 오히려 시간 차이가 더해짐.
- mel raw는 고장 녹음 vs 깨끗한 정상 녹음을 0.97–0.99로 가름 → 녹음 단위 차이(시점·원본 음원)를 잡는 것. 섞인 녹음 안에서는 0.48.
- 방향 구분이 가장 나은 것은 지식 규칙 raw(앞·뒤 0.61)로, 1·2곳 지도학습(0.59)과 비슷.

## 추가: 정상/고장 녹음은 왜 그렇게 잘 갈리나 (같은 날)
- mel raw 점수: 깨끗한 정상 녹음 조각 6.3, 고장 녹음 속 **정상** 조각 12.8, 고장 조각 13.3. 깨끗한 정상 vs 고장 녹음 속 정상 조각 AUC 0.966.
- 시점 때문 아님: 11/09 정상 녹음(09:30–09:44)과 바로 뒤 고장 1곳 녹음(09:45–10:00) 비교도 AUC 0.98. 정상 녹음 안에서 시간에 따른 변화 없음(상관 −0.05).
- 정상 스피커의 원본은 모두 Healthy 폴더 파일(정상 맞음).
- 모든 고장 종류의 녹음에서 같은 모양의 차이(깨끗한 정상 대비): 300–700 Hz −3 dB, 700–1,500 Hz +3~4 dB, 1,500–2,500 Hz +5~7 dB (Whine은 +11 dB). 정상 조각·고장 조각 모두 같음 → 고장 설계 성분이 아니라 고장 원본 파일들의 공통 성질이 모든 방향으로 들림.
- 원본 파일 생성 날짜: Healthy 2024-08-26, Imbalance·Whine·Wind 2024-10-08, Modulation·PWM 2025-01-07 → 정상 파일과 고장 파일이 다른 합성 묶음. 고장 파일의 정상 order 성분(약 0.7–2.5 kHz)이 더 큼(앞서 order 4 차이와 같은 현상)으로 추정.
- 결론: 정상/고장 녹음 구분의 상당 부분은 "고장 파일이 다른 묶음으로 만들어져 기본 소리가 다르다"를 잡는 것일 수 있음. 고장 성분 자체 판별 성능은 이보다 낮을 것.
