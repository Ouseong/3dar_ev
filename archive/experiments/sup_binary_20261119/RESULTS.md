# 정상/고장 2종 지도학습 — 선배 메모 구조, 스펙트로그램만 (2026-11-19)

## 설정
- 구조(선배 메모): 구간 스펙트로그램 → CNN(32/64/128) 벡터 → FCN → latent 64 → decoder(정상/고장)
- 코드: `run_binary.py` = `3DAR_EV_all_in_one.ipynb` 셀 1–2를 그대로 추출. 바꾼 것: out_dir=`runs/nb_binary_spec_20261119`, tasks=['id'](SSL 끔). id_task='binary', use_psd=False, use_rpm=False(노트북 기본값).
- 구간: 앞 135–225°, 오른쪽 225–315°, 뒤 315–360° + 0–45°(따로 인코딩). 분할: 녹음 단위 8:1:1, seed 42/43/44(AE 실험과 같음). 50 epoch, 검증 macro-F1 최고 시점 저장. 임계값 0.5 고정. GPU 약 50%.
- 로그: `runs/nb_binary_spec_20261119.log`
