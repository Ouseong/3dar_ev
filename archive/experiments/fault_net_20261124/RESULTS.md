# FaultBandNet — 고장 대역 × 마이크 각도 지도를 넣는 신경망 (2026-11-24)

- 입력 `build_inputs.py`: 녹음마다 지도 3장(각도 36칸 × 주파수) — Wind 3.3–6.2 kHz(58칸, 양옆 직선 제거), PWM 4.8–5.2 kHz(68칸, 5.9 Hz 간격, 각도칸 중앙값 제거), Whine order 16 ±150 Hz(51칸). 모두 녹음 안 상대값.
- 모델 `train_fault_net.py`: 지도별 2D CNN 가지(conv 3층, 각도 방향 원형 패딩) → 각도별 특징 192채널 → 각도 방향 1D CNN 2층 → FC → 출력 9개(위치 3 × 고장 3종 Whine/PWM/Wind, sigmoid). 파라미터 145,417개. BCE(양성 가중), AdamW 1e-3, 최대 80 epoch, 검증 AUC로 조기 종료. Imbalance·Modulation 스피커는 라벨 0.
- 평가: (cv5) 오른쪽 스피커 원본 파일 단위 5-fold, 학습 fold의 15 %를 검증으로. (strict) 원본 파일이 전혀 안 겹치는 분할 seed 42/43/44(시험 81–88개라 고장 수가 적음). 결과 `runs/fault_net_20261124/summary.json`.

## 평가
- Whine·PWM 검출과 위치 구분은 신경망이 규칙보다 같거나 나음. Wind는 로지스틱 회귀(0.95)보다 낮음(0.82) — 개선 필요.
- 11/02 정상 녹음 20개 오탐 45 %는 그대로(주로 Wind·PWM 출력). 녹음 조건 영향이 남아 있음.

- Imbalance: 고장 블록 녹음이면 대부분 Imbalance로 표시(11/02 정상 85 %, 다른 고장 녹음 48 %) → 고장 성분이 아니라 녹음 조건을 배움.
- Modulation: 겉보기 AUC는 높지만 Modulation 녹음 195개가 모두 RPM A 대역(5,000–7,000)뿐. A 대역 녹음끼리만 비교하면 블록 안 AUC 0.58 → RPM 대역을 구분한 것. 원본에서도 이 RPM 구간에는 Modulation 성분이 거의 없음(5,000–7,000 RPM +1 dB, 3,000–5,000 RPM +13 dB).
- 참고: Whine도 B 대역에만 있지만 B 대역 안 비교에서 0.99 → 실제 성분을 잡음.
- 5종으로 늘리면 고장 1곳 녹음의 종류 정확 0.26, 세 방향 모두 맞힘 0.26으로 3종 모델(0.50–0.59)보다 나빠짐. → 3종 모델 유지.
