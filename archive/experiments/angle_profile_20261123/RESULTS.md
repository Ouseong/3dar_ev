# 각도별 소리 크기 · 마이크 지향성 · 스피커 분리 (2026-11-23)

## 1. 고장 1곳 녹음의 각도 곡선 (`angle_profile.py`, `figures/angle_profile_1fault.png`)
- 정상 녹음 평균을 뺀 대역별 크기가 고장 위치와 관계없이 0–50°(녹음 시작)에서 가장 크고 360°로 갈수록 감소 → 방향이 아니라 시간(RPM) 패턴. 고장 스피커 방향에서 솟지 않음.

## 2. 마이크 지향성, 1개 스피커 정상 녹음 (`directivity_1spk.py`, `figures/directivity_1speaker.png`)
위치별 각도 곡선에서 세 위치 평균을 빼 시간 변화를 지운 모양(dB):
| 대역 | 오른쪽만 재생 | 뒤만 재생 | 앞만 재생 |
|---|---|---|---|
| 1.5–5.75 kHz | 최대 255–265°, 범위 7–9 dB | 최대 355°, 범위 3–4 dB | 최대 5°, 185° 부근 작은 봉우리, 범위 6–7.5 dB |
| < 1.5 kHz | 뚜렷하지 않음 | 뚜렷하지 않음 | 뚜렷하지 않음 |
- 오른쪽 스피커는 가정한 270°에서 뚜렷하게 잡힘. 뒤는 약함. 앞은 180°에서 솟지 않고 0°(녹음 시작) 쪽이 큼 → 앞 180° 기하 가정 확인 필요(CLAUDE.md 5번의 미확인 가정).
- 앞 스피커가 전체적으로 6–9 dB 작게 녹음됨.

## 3. 지향성으로 스피커 분리 (`unmix_speakers.py`)
- 3개 스피커 녹음 각도 곡선 = Σ 스피커 크기 × 1개 스피커 지향성 곡선, 대역별 NNLS. 분리한 스피커 스펙트럼을 정상 기준(원본 음원 안 겹침)과 비교.
- 고장 1곳 녹음에서 고장 스피커 1등: 분리 0.28, 구간 평균 0.33, 5 kHz 선 0.41–0.42 (무작위 0.33). 앞·뒤 비교 0.44–0.54.
- 분리 효과 없음. 녹음마다 원본 파일의 시간 변화가 달라 평균 지향성 곡선이 맞지 않음.

## 지금 데이터로 쓸 만한 특징
1. 녹음 단위 고장 여부(0.7–2.5 kHz 차이, 파일 묶음 차이 포함 주의) — 0.94.
2. 오른쪽 vs 나머지 방향 구분(1.5–6 kHz 지향성 7–9 dB).
3. PWM 5 kHz 선의 구간별 주변 대비 크기 — 고장 구간이 가장 큼 70% (`knowledge_rules_20261123`).
4. Whine order 16 선 — 고장 여부는 잘 잡히나 방향은 시간과 섞임.

## 4. 고장 성분 자체가 고장 스피커를 향할 때 커지나 (`fault_component_direction.py`, `figures/fault_component_direction.png`)
같은 고장 종류의 앞 녹음과 뒤 녹음 곡선 차이(시간 변화 상쇄), Wind는 정상 대비. 향할 때 − 반대일 때(dB):
| 고장 (성분) | 1개 스피커 | 3개 스피커 고장 1곳 |
|---|---|---|
| PWM (5 kHz 선) | **+7.3** (앞 최대 205°, 뒤 최대 15°) | +2.0 (뒤만 뚜렷) |
| Wind (3.75–5.75 kHz) | **+5.3** (오른쪽 270–300°에서 +6.5, 녹음 시작 봉우리도 있음) | −3.3 (녹음 시작 효과가 지배, 270°에 작은 봉우리) |
| Whine (order 16, 약 2 kHz) | +0.7 (곡선이 파일 시간 위치에 좌우) | 0.0 |
| Modulation (order 8, 약 0.8 kHz) | −0.4 (뒤 파일이 전 각도에서 4–6 dB 큼) | −0.1 |
| Imbalance (order 1·2, 0.1–0.3 kHz) | +0.2 | +0.2 |
- 마이크 지향성은 1.5 kHz 이상에서만 있음 → 고음 고장(PWM, Wind)만 향할 때 커짐. 저음 고장(Imbalance, Modulation)은 물리적으로 방향 차이 없음.
- Whine은 2 kHz지만 order 16 강조 구간이 파일마다 다른 시점이라 방향 효과가 시간에 묻힘.
- 3개 스피커에서는 다른 스피커 소리·파일 묶음 차이 때문에 PWM도 +2 dB로 줄어듦.

## 5. 3DAR 논문(Ahn et al., RCIM 94 (2025) 102970)과 비교
- 구조: 지름 32.5 mm · 길이 167.4 mm 관에 슬롯 33개, 슬롯 간 경로차 d(1−cosθ)가 반파장 근처일 때 상쇄. 반무향실, 2 m, 순음 94 dB로 지향성 측정(Fig. 1B). 위치 추정은 500 Hz–22 kHz 대역통과 → 각도별 평균 파워 → 피크. 실험 회전 속도 1/14 rev/s(이번 녹음은 약 1/4 rev/s).
- Fig. 1B: 500 Hz는 거의 무지향, 1 kHz 약함, 2 kHz부터 뚜렷, 5·10 kHz는 좁은 주엽(측면 −9 dB 이하). 관 길이(167 mm)가 파장(2 kHz ≈ 170 mm)에 가까워질 때부터 상쇄가 작동하는 구조.
- 이번 측정(1.5 kHz 미만 0 dB, 1.5–6 kHz 3–9 dB)은 설계 원리와 일치. 크기가 논문보다 작은 것은 일반 방 반사, 가속음(비정상 신호), 빠른 회전 때문으로 추정.
- 따라서 Imbalance(0.1–0.3 kHz)·Modulation(0.8 kHz)은 3DAR 작동 대역 밖 → 어떤 모델로도 3DAR 방향 정보로 위치를 알기 어려움. PWM(5 kHz)·Wind(4–5.5 kHz)는 대역 안(실측 +7, +5 dB). Whine(약 2 kHz)은 경계.
